How to Edit These Notes

A minimal guide

A short guide to editing, organizing, previewing, and publishing these notes.

你平时只需要编辑扩展名为 .qmd 的源文件。它和 Markdown 几乎一样，但对数学公式、目录和提示框支持得更好。侧边栏、首页卡片、主题目录和 HTML 都由 Quarto 根据这些源文件自动生成。

修改一篇笔记

在 VS Code 左侧文件列表中打开对应的 .qmd 文件，直接修改文字并保存即可：

## A new section

普通文字写在这里，行内公式写成 $X \to Y$。

$$
\Omega_{X/Y}=0
$$

以 --- 包围的文件开头是页面信息。每篇正式笔记都需要填写：

---
title: "A New Note"
subtitle: ""
description: "A short description shown on the topic page."
order: 80
---
  • title 是页面标题以及侧边栏中的名称。
  • description 是主题目录中显示的一句话简介。
  • order 是阅读顺序，必须写成数字。现有页面以 10 为间隔排列，因此可以把新页面插入中间，例如在 40 和 50 之间使用 45。
  • subtitle 可以留空。

修改并保存后，本地预览会自动重新生成相应的 HTML。

删除一篇笔记

删除对应的 .qmd 文件即可。下一次预览或构建时，Quarto 会自动把它从侧边栏和主题目录移除。

如果其他笔记的正文中手动链接了被删除的页面，那些正文链接仍需自行修改。

新增一篇笔记

在已有主题的文件夹中，新建一个 .qmd 文件并填写 title、description 和 order。例如：

---
title: "Examples"
description: "Examples illustrating the main definitions and geometric intuition."
order: 45
---

文件保存后，不需要修改 _quarto.yml 或主题的 index.qmd：新页面会自动出现在侧边栏、主题目录和生成的网站中。

新增一个大主题

新建一个主题文件夹，并在其中创建 index.qmd。文件夹名称最好使用小写英文和连字符，例如 perfectoid-spaces。主题首页可以使用下面的模板：

---
title: "Perfectoid Spaces"
subtitle: ""
description: "Notes on perfectoid spaces and their applications."
order: 30
start-page: "perfectoid-spaces/first-note.qmd"
toc: false
listing:
  id: topic-pages
  contents: "*.qmd"
  template: "../_templates/topic-pages.ejs.md"
  fields: [title, description, order]
  sort: "order asc"
  sort-ui: false
  filter-ui: false
---

Write the introduction to this topic here.

Tip最省事的工作方式

你也可以复制同一主题中的现有 .qmd，只修改文件名、页面信息和正文。只要 title、description 和 order 完整，目录不需要手工维护。

本地预览

在英文路径的工作目录 C:\notes\p-adic-geometry-note 中打开 VS Code，然后在终端运行：

.\preview-local.ps1

终端会显示一个 http://localhost:... 地址。保持这个终端运行，保存 .qmd 文件后网页会自动刷新；结束预览时按 Ctrl+C。

确认预览无误后，把修改 commit 并 push 到 main。GitHub Actions 会重新构建并发布网站。
